# یادداشت بررسی دیداری بازطراحی حساب PartyPlay

## ۲۱ اوت ۲۰۲۶ — پیش‌نمایش محلی

فرم ورود و تب ساخت حساب با مقادیر عمومی آزمایشی Supabase در Vite بررسی شد؛ هیچ راز یا نشست واقعی برای این بررسی استفاده نشد.

| ناحیه | نتیجه |
|---|---|
| فرم ورود | صفحهٔ جدا، ساده و مرتب با ایمیل، رمز، نمایش/پنهان‌سازی رمز، بازیابی رمز و مسیر جایگزین لینک ایمیلی نمایش داده شد. |
| ثبت‌نام | تب جدا با نام، آیدی، ایمیل، رمز، تکرار رمز، ساخت رمز امن و کپی رمز نمایش داده شد. |
| چیدمان | در ارتفاع استاندارد دسکتاپ، فیلدهای انتهایی فرم ثبت‌نام با اسکرول در همان کارت قابل دسترسی هستند؛ کارت از viewport خارج نمی‌شود. |
| متن آواتار | در مسیر ثبت‌نام هیچ متن «چهرهٔ هندسی» مشاهده نشد. |

اقدام بعدی: اتصال migration و Edge Function اعلان، سپس بررسی تنظیمات و مرکز اعلان با دادهٔ واقعی پروژه.

پس از ویرایش ترجمه‌ها، Vite صفحه را با hot reload بازنشانی کرد و فرم به تب ورود برگشت؛ این رفتار محیط توسعه است و نشانهٔ خطای مسیر ثبت‌نام نیست. بررسی تعاملی دکمهٔ ساخت رمز پس از تثبیت کامل bundle تکرار می‌شود.
