# فهرست بازی‌های متن‌باز پیشنهادی برای «پارتی پلی»

## جمع‌بندی اجرایی

حق با توست که بازی‌های شناخته‌شده و آزموده‌شدهٔ متن‌باز، نقطهٔ شروع بهتری از ساختن هر بازی از صفر هستند. من مخزن‌های GitHub را با چهار معیار غربال کردم: **مجوز قابل‌استفاده، کیفیت و فعالیت کد، قابلیت اجرای مرورگری، و امکان تبدیل لایهٔ همگام‌سازی آن‌ها به React + Supabase + GitHub Pages**. نتیجه این است که چند بازی ارزش اقتباس واقعی دارند، اما «کپی‌کردن کامل یک مخزن» معمولاً انتخاب درستی نیست؛ چون اغلب به Firebase، Socket.IO، Redis یا یک سرور مجزا وابسته‌اند. مسیر درست این است که منطق بازی، مؤلفه‌های رابط و الگوی UX از منبع متن‌باز گرفته شود، سپس اتاق خصوصی، احراز هویت و Realtime با زیرساخت خود پارتی پلی یکپارچه شود.

> **معیار حقوقی:** فقط گزینه‌های دارای مجوز روشن، به‌خصوص MIT یا CC0، برای استفادهٔ مستقیم یا اقتباس پیشنهاد شده‌اند. پروژه‌های AGPL، GPL، بدون مجوز، یا دارای محتوای تجاریِ قابل کپی، در ستون «محدودیت» مشخص شده‌اند.

## پیشنهاد من برای موج اول

اگر بخواهم فقط بازی‌هایی را انتخاب کنم که هم **واقعاً جذاب** هستند و هم می‌توان از مخزن‌های متن‌باز برایشان پایهٔ قابل اتکا برداشت، این ترتیب را پیشنهاد می‌کنم:

| اولویت | بازی | دلیل انتخاب |
|---:|---|---|
| 1 | جاسوس | اجتماعی، نقش مخفی، مناسب فارسی‌سازی و بسیار نزدیک به مخاطب پارتی پلی. |
| 2 | اونو / هفت‌خبیث | ورق، رقابت سریع و کد متن‌باز بالغ‌تر از بقیهٔ گزینه‌ها. |
| 3 | بکش و حدس بزن | تجربهٔ گروهیِ پرتعامل و عالی برای موبایل و چت. |
| 4 | منچ | بازی آشنا و خواسته‌شده؛ پایهٔ MIT موجود است. |
| 5 | مارپلهٔ جدید | کد آنلاین MIT با انیمیشن، اتاق و نوبت همگام موجود است؛ جایگزین معقول نسخهٔ فعلی. |
| 6 | چهاردرردیف | جایگزین مستقیم و بهتر برای دوز؛ هم دوست و هم ربات. |
| 7 | تخته‌نرد | بازی ماندگار دونفره، اما باید با دقت و مرحله‌ای بازطراحی شود. |

## تصمیم موردنیاز از تو

فقط شمارهٔ بازی‌هایی را که می‌خواهی وارد «موج اول» شوند بفرست. بعد از تأیید تو، هر بازی را با این قاعده اضافه می‌کنم: **اول منبع و مجوز را در مخزن ثبت می‌کنم، سپس بخش‌های مجاز را اقتباس یا بازنویسی می‌کنم، و در نهایت Realtime، اتاق خصوصی، RTL فارسی، آواتار و طراحی پارتی پلی را یکپارچه می‌کنم.** بدون تأیید، هیچ بازی فعلی حذف یا جایگزین نمی‌شود.
