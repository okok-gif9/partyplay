| مارپله → بازی با ربات → تاس | موفق | پس از تاس کاربر، موقعیت هر دو مهره به‌روز شد و کنترل پس از حرکت ربات به کاربر بازگشت. |
| منچ → بازی با ربات → تاس | موفق | پس از تاس کاربر، هر سه رقیب ربات حرکت کردند و نوبت دوباره به کاربر برگشت. |

| بکش‌وحدس‌بزن → بازی با ربات → حدس | موفق | صفحهٔ نقاشی و دکمهٔ حدس فعال بودند و ربات پاسخ درست/راهنماییِ دور را نمایش داد. |
| رمز → بازی با ربات → انتخاب کارت | موفق | با انتخاب کارت کاربر، ربات پس از نوبت خود یک کارت دیگر را آشکار کرد. |
| تخته‌نرد → بازی با ربات → تاس | موفق | تاس کاربر، موقعیت مهره‌های کاربر و سپس حرکت پاسخ ربات روی تخته ثبت شد. |
| حکم → بازی با ربات → بازی ورق | موفق | با بازی یک ورق، شمار دست کاربر و ربات هر دو به‌روزرسانی شد. |
| جرئت‌وحقیقت → شروع فوری → کارت جرئت | موفق | بدون گروه باز شد و با انتخاب «جرئت بعدی»، کارت و وضعیت تمرین به‌درستی تغییر کرد. |
| مافیا → اتاق دوستان | موفق | کارت مستقیماً به انتخاب ظرفیت‌های ۵، ۷ و ۹ نفره برای لابی خصوصی هدایت شد. |

## موارد باز برای آزمون

- آزمون ساخت واقعی اتاق آنلاین پس از احراز هویت در Supabase؛ نسخهٔ عمومی پیش از ورود فقط صفحهٔ ورود امن را نمایش می‌دهد.
- هدایت «اتاق دوستان» برای جرئت‌وحقیقت و دوز، و ساخت واقعی یک اتاق آزمایشی پس از احراز هویت.
- ساخت اتاق‌های آنلاین و آزمون رخدادهای Supabase پس از ورود.
