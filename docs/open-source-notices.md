# Open-source game references and notices

This project studies and, where compatible, adapts code patterns from the sources listed below. The PartyPlay product ships an independent Persian UI, Supabase integration, original copy, original word packs and original artwork. Source licenses must be retained whenever code is copied or distributed.

| Reference | License | Intended use in PartyPlay |
|---|---|---|
| https://github.com/adrianocola/spyfall | MIT | Spyfall game flow and localization structure; original Persian locations and wording. |
| https://github.com/guilhermebkel/uno-game | MIT | Turn flow and card-game interaction patterns; independent PartyPlay card assets and Supabase integration. |
| https://github.com/Arp-G/pictionary | MIT | Drawing/guessing room interaction patterns; independent implementation and Persian word packs. |
| https://github.com/caleb531/connect-four | MIT | Four-in-a-row rules, bot and interaction patterns. |
| https://github.com/quasoft/backgammonjs | MIT | Backgammon rules and turn-flow reference. |
| https://github.com/AdheeshaRavindu/Snake-and-Ladder | MIT | Multiplayer Snake & Ladder interaction and sound-flow reference. |
| https://github.com/CyberCitizen01/LUDO | MIT | Ludo room and move-flow reference. |
| https://github.com/koosvary/codenames | MIT | Team word-game interaction patterns; no commercial word packs are copied. |
| https://github.com/matin-as/Online-hokm-game | CC0-1.0 | Hokm room and feature reference only; the Unity/Photon code is not bundled. |
| https://github.com/Jezternz/PlayMafia | MIT | Mafia role and phase reference; the legacy Redis/SockJS code is not bundled. |

The following repositories are **not copied or bundled** because their license or provenance is unsuitable for direct inclusion: LibreLudo (AGPL-3.0), AlecM33/Werewolf (GPL-3.0), Soupaul/snakes-and-ladders-multiplayer (no declared license), simondiep/quiplash-js (no declared license), and therewillbecode/react-poker (no declared repository license).
