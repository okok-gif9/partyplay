# گزارش آزمون انتقال مارپلهٔ واقعی

**منبع منتقل‌شده:** `mohammadnedaei/Snakes-Ladders-React`، دارای مجوز MIT.

| سناریو | نتیجه | مشاهده |
|---|---|---|
| ساخت منبع اصلی با مسیر نسبی | موفق | خروجی Vite با دارایی‌های برد و پس‌زمینهٔ اصلی تولید شد. |
| فارسی‌سازی و راست‌به‌چپ | موفق | منوی آغاز، تنظیمات، تأیید شروع، وضعیت نوبت و نتیجهٔ بازی فارسی شدند. |
| ورود از کارت «مارپله → بازی با ربات» | موفق | قاب یکپارچهٔ بازی اصلی باز شد؛ نسخهٔ نمایشی قبلی نمایش داده نشد. |
| منوی اصلی و تنظیمات | موفق | انتخاب تعداد بازیکن، ترتیب رنگ مهره‌ها، فعال‌سازی CPU و تأیید شروع در قاب سایت عمل کردند. |
| برد و تاس سه‌بعدی | موفق | برد گرافیکی اصلی، تاس سه‌بعدی، مهره‌ها و وضعیت نوبت در نسخهٔ یکپارچه دیده شدند. |
| گردش نوبت و ربات | موفق | پس از دو نوبت بازیکن، رباتِ فعال‌شده به‌طور خودکار تاس انداخت و نوبت به بازیکن اول بازگشت. |
| اتاق دوستان | حفظ شد | دکمهٔ مستقل اتاق دوستان همچنان به لابی آنلاین Supabase مارپله می‌رود. |

## نکتهٔ انتقال

به‌خاطر این‌که گزینهٔ CPU در منبع وجود داشت اما حرکت خودکار انجام نمی‌داد، تنها اصلاح منطقیِ افزوده‌شده، پرتاب خودکار تاس برای بازیکن CPU پس از رسیدن نوبت اوست. قوانین، برد، تاس، ترتیب نوبت، دارایی‌های گرافیکی و تجربهٔ اصلی پروژه از منبع منتقل‌شده حفظ شده‌اند.
