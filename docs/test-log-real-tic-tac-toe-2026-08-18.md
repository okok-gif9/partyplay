# آزمون انتقال واقعی دوز

| سناریو | نتیجه | شاهد مشاهده‌شده |
|---|---|---|
| ساخت تولیدی | موفق | `pnpm build` بدون خطا اجرا شد و `index.html`، `script.js` و `LICENSE` بازی منتقل‌شده در خروجی تولید قرار گرفتند. |
| مسیر کارت «دوز کلاسیک → بازی با ربات» | موفق | کارت، صحنهٔ میزبان «بازی اصلی منتقل‌شده» را باز کرد؛ نسخهٔ شبکه‌ای سادهٔ قبلی نمایش داده نشد. |
| بارگذاری بازی واقعی در iframe محلی | موفق | صفحهٔ اصلی منبع با انتخاب X/O، سه دشواری ربات و دکمهٔ شروع داخل قاب سایت بارگذاری شد. |
| آغاز یک دور | موفق | با کلیک شروع، تابلوی اصلی ۳×۳، راه‌اندازی نوبت و کنترل شروع دوباره ظاهر شد. |
| حرکت بازیکن و پاسخ ربات | موفق | حرکت X در خانهٔ انتخابی ثبت شد، نشانگر «ربات در حال فکر کردن» ظاهر شد و سپس O ربات در خانهٔ مرکزی قرار گرفت. |
| مسیر «اتاق دوستان» | حفظ شد | دکمهٔ جداگانهٔ اتاق دوستان در میزبان بازی وجود دارد و به سازندهٔ لابی Supabase دوز متصل است. |
| بازآزمون پس از حذف نسخهٔ نمایشی | موفق | کارت دوز دوباره باز شد و فقط میزبان بازی واقعی با کنترل‌های انتخاب مهره، دشواری و شروع بازی نمایش داده شد. |

## محدودیت آزمون

ساخت واقعی یک اتاق Supabase در این دور آزمون نیازمند احراز هویت کاربر است و جدا از دوز محلی منتقل‌شده باقی می‌ماند.
