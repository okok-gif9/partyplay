# ارزیابی منبع رمز

## گزینهٔ انتخاب‌شده

- منبع: [nazmus2575/bangla-codenames](https://github.com/nazmus2575/bangla-codenames)
- commit بررسی‌شده: `4fc4cba`
- مجوز: MIT؛ فایل `LICENSE` مجوز آزاد استفاده، تغییر و انتشار را اعلام می‌کند.
- فناوری: HTML، CSS و JavaScript خالص؛ بدون build، dependency یا backend.

## قابلیت‌های تأییدشده

این منبع یک بازی کامل رمز با برد استاندارد ۵×۵ است. موتور، برای هر کد شش‌کاراکتری یک انتخاب قطعی از ۲۵ کارت و کلید رنگی ۹/۸/۷/۱ می‌سازد؛ بنابراین لینک یا کد یکسان، همان برد را در هر دستگاه بازسازی می‌کند و برای انتشار استاتیک GitHub Pages مناسب است. حالت «کلید محرمانه» رنگ‌ها را فقط روی دستگاه رمزدار آشکار می‌کند. امتیاز تیم‌ها، نوبت، کارت خنثی و باخت فوری با کارت قاتل نیز در همان موتور منبع اجرا می‌شوند.

## فارسی‌سازی و محتوا

قالب صفحه، کنترل‌ها، اعلان‌ها، قوانین و فونت به فارسی و راست‌به‌چپ تبدیل شده است. بانک واژهٔ بنگالی منبع با ۴۴۵ واژهٔ فارسیِ آشنا و قابل‌سرنخ‌دهی در دسته‌های طبیعت، جانوران، خوراکی‌ها، مکان‌ها، فناوری، هنر و مفاهیم جایگزین شد. مکانیک و الگوریتم قطعی موتور بدون تغییر باقی مانده‌اند؛ برای سازگاری تنها نام عمومی متغیر واژهٔ منبع حفظ شده است.

## آزمون پذیرش

نسخهٔ استاتیک روی میزبان محلی باز شد. برد ۲۵تایی با واژه‌های فارسی، تولید کد دعوت، نمایش وضعیت تیم‌ها و حالت کلید محرمانه با رنگ‌های خصوصی به‌صورت بصری تأیید شدند.
