# ارزیابی منبع اونو

## گزینهٔ انتخاب‌شده

- منبع: [Justinjdaniel/UnoDeck-TinyToys](https://github.com/Justinjdaniel/UnoDeck-TinyToys)
- commit بررسی‌شده: `acf4239`
- مجوز: MIT؛ فایل `LICENSE` شامل «Copyright (c) 2026 Justin J Daniel» است.
- فناوری: React 19، TypeScript، Vite، Framer Motion و Web Audio API.
- اجرای مستقل: هیچ فراخوانی شبکه یا socket در `src/` دیده نشد؛ خروجی Vite با `base: './'` برای GitHub Pages مناسب است.

## قابلیت‌های تأییدشده

نسخهٔ ساخته‌شده در پیش‌نمایش محلی اجرا شد. بازی حالت «VS BOT (AI)» دارد و ربات داخلی پس از حرکت کاربر به‌صورت خودکار کارت بازی می‌کند، رنگ کارت wild را انتخاب می‌کند و در آزمون پس از کارت آبی کاربر، یک wild draw four اجرا کرد. منبع شامل موتور bot با درخت تصمیم، مکث طبیعی ۸۰۰ تا ۱۲۰۰ میلی‌ثانیه و منطق standard action cards است.

## ملاحظات انتقال

رابط فعلی طراحی نئونیِ حرفه‌ای و مناسب قاب پارتی پلی دارد، اما متن‌های آن انگلیسی است. فارسی‌سازی باید به متن‌های قابل‌مشاهده محدود بماند؛ قوانین، موتور کارت‌ها، AI، صدا و انیمیشن منبع حفظ خواهند شد. فایل‌های `LICENSE` و `ATTRIBUTION.md` در خروجی بازی نگه‌داری می‌شوند و attribution داخل صفحهٔ بازی نمایش داده نخواهد شد.
