# ارزیابی منابع چهاردرردیف

## معیار انتخاب

منبع باید مجوز روشن، بازی کامل، طراحی قابل‌قبول، ربات واقعی، و اجرای قابل‌اتکا روی GitHub Pages داشته باشد. پروژه‌های صرفاً نمایشی یا وابسته به سرور خصوصی بدون مسیر مستقل ربات رد یا محدود می‌شوند.

| منبع | مجوز و کیفیت | نتیجهٔ آزمون | تصمیم |
|---|---|---|---|
| [`caleb531/connect-four`](https://github.com/caleb531/connect-four) | MIT، نگهداری فعال تا مه ۲۰۲۶، آزمون Playwright، ربات Minimax با alpha-beta pruning، بازی موبایل/دسکتاپ و رابط مستقل. | با زنجیرهٔ اصلی Vite ساخته شد. خروجی استاتیک منوی یک‌نفره را نشان می‌دهد اما حرکت کامل به session سرور منبع وابسته است؛ اجرای کامل با سرور اصلی روی پورت ۸۰۸۰ کار می‌کند. | مکانیک و کیفیت کد بسیار قوی؛ برای GitHub Pages باید لایهٔ ربات محلی منبع از server session جدا شود یا نسخهٔ کامپایل‌شده با bridge سبک استفاده شود. |
| [`jeanwl/ConnectFour`](https://github.com/jeanwl/ConnectFour) | ظاهر Frontend Mentor بسیار چشمگیر، انیمیشن و حالت CPU دارد. | فایل LICENSE صریح در ریشه دیده نشد؛ دارایی‌ها و شرایط استفاده برای انتقال مطمئن نیستند. | رد به علت ابهام حقوقی، با وجود کیفیت بصری بالا. |
| [`kenrick95/c4`](https://github.com/kenrick95/c4) | MIT، TypeScript/Canvas، AI مبتنی بر Minimax و alpha-beta pruning، نگهداری فعال. | دموی زنده اجرا شد؛ طراحی بصری بیشتر فنی و خاکستری است و از معیار ظاهری پارتی پلی پایین‌تر است. | رد برای انتقال فعلی به‌علت طراحی قدیمی‌تر. |
| [`shrinil-thakkar/connect4`](https://github.com/shrinil-thakkar/connect4) | MIT و ظاهر مدرن با مهره‌های افتان و ربات داخلی. | فایل `public/game.js` برای لابی و نام‌گیری به Socket.IO وابسته است، اما منطق ربات و برد در کلاینت وجود دارد. دموی عمومی مقصد دیگر فعال نیست. | کاندیدای مشروط؛ تنها در صورت استخراج ایمن حالت ربات از منطق اصلی و حذف وابستگی لابی برای GitHub Pages. |

## نتیجهٔ فعلی

هیچ منبعی بدون اصلاح کوچکِ سازگاری یا سازوکار سرور، هم‌زمان همهٔ معیارهای اجرا روی GitHub Pages و طراحی سطح محصول را ندارد. برای حفظ درخواست کاربر مبنی بر «بازی واقعی» و جلوگیری از نمونه‌سازی ساده، انتقال چهاردرردیف باید بر منطق منبع دارای مجوز تکیه کند و هر سازگاری فقط به جدا کردن مسیر ربات از لابی سرور محدود بماند.
