این نتیجه به‌معنای رد مفهوم بازی حافظه نیست؛ فقط این مخزن منبع قابل انتقال نیست. جست‌وجو برای بازسازی‌های مستقلِ مرورگری و قانونی ادامه دارد.

### جست‌وجوی گستردهٔ GitHub

جست‌وجوی عمومی GitHub نامزدهای مرورگری مانند `zkjon/PurblePlace`، `muneeb299-it/PurblePlace`، `jchow7/purble-place`، `CodeByKaran/PurblePlace` و `rapha-pro/Memory-game` را نشان داد؛ اما خروجی مخزن‌ها برای این نامزدها مجوز اعلام‌شده نداشت. مخزن‌های فاقد مجوز صریح برای انتقال به پارتی پلی پذیرفته نمی‌شوند، حتی اگر JavaScript یا HTML باشند.

برخی نامزدهای دیگر نیز فناوری نامناسب داشتند: نسخه‌های AutoHotkey، C#، Python یا ابزار خودکارسازی بازی رسمی، اجراشدنی در GitHub Pages نیستند یا مستقیماً به نسخهٔ رسمی وابسته‌اند. بنابراین فعلاً هیچ منبع قانونی و حرفه‌ای برای بستهٔ سه‌گانهٔ Purble Place پذیرفته نشده است.

| دستهٔ نامزد | وضعیت | دلیل |
|---|---|---|
| JavaScript/HTML بدون مجوز (`zkjon`, `muneeb299-it`, `jchow7`, `CodeByKaran`, `rapha-pro`) | رد | مجوز استفاده و بازنشر شفاف نیست. |
| نسخه‌های AutoHotkey/C#/Python | رد | ناسازگار با اجرای استاتیک مرورگر یا ابزار مرتبط با نسخهٔ رسمی. |
| مخزن دارای دارایی/لانچر رسمی ویندوز | رد | خطر وابستگی به دارایی رسمی و ناسازگاری با سیاست حقوقی محصول. |

**نتیجهٔ فعلی:** Purble Place تا یافتن یک بازسازی مستقلِ مرورگری با مجوز روشن، وارد آرکید نمی‌شود.

## FreeCell و Minesweeper

| منبع | فناوری و مجوز | ارزیابی | تصمیم |
|---|---|---|---|
| [`gitbrent/FreecellJS`](https://github.com/gitbrent/FreecellJS) | HTML5، CSS و JavaScript؛ MIT؛ اجرای دمو روی GitHub Pages؛ ادعای پشتیبانی واکنش‌گرا برای مرورگرهای مدرن. | موتور کامل، استاتیک و قابل انتقال است. نام بازی یک گونهٔ عمومی ورق‌بازی است و پروژه برای مرورگر طراحی شده است. | **نامزد پذیرفته‌شده برای انتقال و آزمون**. |
| [`phartenfeller/minesweeper_js`](https://github.com/phartenfeller/minesweeper_js) | JavaScript/CSS/HTML؛ MIT؛ PWA با تنظیم سختی و آمار. | از نظر فنی کامل و مدرن‌تر است، اما مخزن خود را «Original MS Minesweeper» معرفی می‌کند. پیش از استفاده باید دارایی‌ها و نام‌گذاری برای وابستگی به برند/گرافیک رسمی بازبینی شود. | **در انتظار بررسی حقوقی/دارایی**. |
| [`nickarocho/minesweeper`](https://github.com/nickarocho/minesweeper) | HTML/CSS/JavaScript؛ مجوز در صفحهٔ مخزن اعلام نشده. | ظاهر نوستالژیک دارد، اما مجوز روشن ندارد و خود پروژه به تقلید ظاهر Windows 95 اشاره می‌کند. | **رد**. |

> فقط FreeCell در این مرحله هم‌زمان شرایط مجوز روشن، اجرای استاتیک و تکمیل قواعد را دارد. Minesweeper تا بررسی دارایی‌ها و نام‌گذاری عمومی وارد آرکید نمی‌شود.

### آزمون دیداری FreeCell

دموی عمومی FreecellJS باز شد و یک دست واقعی آغاز شد. صفحهٔ شروع، گزینه‌های راهنما و تنظیمات و سپس میز کامل با چهار خانهٔ آزاد، چهار بنیاد و هشت ستون کارت نمایش داده شد. رابط در مرورگر بدون نیاز به سرور اختصاصی کار می‌کند و از گرافیک کارت عمومی استفاده می‌کند؛ نشانه‌ای از دارایی رسمی Purble Place یا ویندوز در این آزمون دیده نشد.

**نتیجه:** FreecellJS همچنان گزینهٔ مناسب برای مرحلهٔ انتقال است، مشروط به آزمون محلیِ مسیرهای نسبی پس از دریافت مخزن.
