# ارزیابی منبع جاسوس

## گزینهٔ انتخاب‌شده

- منبع: [mmattia09/impostor](https://github.com/mmattia09/impostor)
- commit بررسی‌شده: `fa1f618` (`v1.2.0`)
- مجوز: MIT؛ فایل `LICENSE` شامل «Copyright (c) 2026 mmattia09» است.
- فناوری: HTML، CSS و JavaScript خالص؛ بدون وابستگی یا مرحلهٔ build.
- اجرای مستقل: داده‌ها از فایل‌های JSON محلی با `fetch` خوانده می‌شوند و وضعیت بازی در `localStorage` باقی می‌ماند؛ socket، backend یا سرویس ابری ندارد.

## قابلیت‌های تأییدشده

منبع یک بازی نقش مخفیِ تک‌دستگاهی و کامل است: نقش شهروند، جاسوس و بازیکن بی‌خبر، گذراندن امن تلفن، راهنمای اختیاری برای جاسوس، انتخاب آغازکننده، رأی‌گیری، حدس واژه توسط نقش بی‌خبر، امتیازدهی چند راند و ادامهٔ جلسه پس از تازه‌سازی صفحه. دموی عمومی با رابط واکنش‌گرا و حالت روشن/تاریک در [GitHub Pages منبع](https://mmattia09.github.io/impostor/) بررسی شد.

## فارسی‌سازی و محتوا

قالب صفحه و کنترل‌های آغاز بازی به فارسی تبدیل شده‌اند. یک بستهٔ دادهٔ `packet-farsi.json` با بیش از ۱۰۰ واژه و سرنخ فارسی به همان ساختار دادهٔ منبع افزوده شد و در `manifest.json` و fallback بازی در اولویت قرار گرفت. فارسی‌سازیِ باقی‌ماندهٔ پیام‌های پویای رابط باید پیش از انتقال نهایی تکمیل و با جریان نقش‌دهی، رأی‌گیری و پایان راند آزموده شود.

## منابع ردشده

`adrianocola/spyfall` دارای مجوز MIT، جامعهٔ کاربری بزرگ و ترجمهٔ فارسی است، اما مسیر اتاق آنلاین آن به Firebase وابسته است و برای اجرای کامل روی GitHub Pages بدون زیرساخت اضافی مناسب نیست. `VeryBadFrags/spyfall` نیز MIT است اما اجرای چندنفره‌اش به Node و Socket.IO وابسته است.
