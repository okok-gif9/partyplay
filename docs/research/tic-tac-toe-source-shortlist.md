# فهرست کوتاه منابع دوز برای انتقال نخست

## معیارهای پذیرش

هر بازی باید کد واقعیِ قابل‌انتقال، مجوز صریح، رابط سطح محصول، نسخهٔ قابل‌اجرا در مرورگر، طراحی واکنش‌گرا و قابلیت‌های بازی فراتر از یک شبکهٔ ۳×۳ داشته باشد. مخزن‌های بدون مجوز روشن رد می‌شوند، حتی اگر طراحی‌شان خوب باشد.

| مخزن | وضعیت مجوز | طراحی و قابلیت‌ها | نتیجه |
|---|---|---|---|
| `VoxDroid/Ultimate-Tic-Tac-Toe` | MIT | چندزبانه، تم قابل تغییر، نام بازیکن، زمان‌سنج، امتیاز، undo، AI، انیمیشن برد و رابط واکنش‌گرا | قابل انتقال، اما ظاهر دموی زنده نسبتاً عمومی و کمتر هم‌راستا با استاندارد بصری هدف است. |
| `kebin20/tic-tac-toe-react` | مجوز صریح در ریشهٔ مخزن مشاهده نشد | رابط بصری بسیار خوب بر مبنای Frontend Mentor، CPU و PvP | رد؛ کد بدون مجوز روشن منتقل نمی‌شود. |
| `ramazancetinkaya/tictactoe` | MIT | طراحی مدرن و واکنش‌گرا، سه درجهٔ دشواری، انتخاب نماد، امتیازدهی، زمان‌سنج، AI مبتنی بر heuristic و روند بازی واقعی | **منبع پیشنهادی برای انتقال نخست.** |

## منبع پیشنهادی

### `ramazancetinkaya/tictactoe`

- نشانی: https://github.com/ramazancetinkaya/tictactoe
- نسخهٔ زنده: https://ramazancetinkaya.github.io/tictactoe/
- مجوز: MIT
- فناوری: HTML5، CSS3 و JavaScript بدون وابستگی
- ویژگی‌های تأییدشده: بازی با CPU، سه درجهٔ دشواری، انتخاب X/O، زمان‌سنج، امتیازدهی نشست و طراحی واکنش‌گرا.
- آخرین commit مشاهده‌شده در مخزن: ۲۹ اوت ۲۰۲۵.

## قرارداد انتقال

کد اصلی `index.html`، `styles.css` و `script.js`، همراه با فایل MIT و attribution، به‌عنوان یک واحد فروشنده/منبع خارجی وارد پروژه می‌شود. تنها سازگارکنندهٔ محدود برای بارگذاری در مسیر React و فارسی‌سازی متون افزوده می‌شود؛ موتور AI و منطق بازی از نو نوشته نخواهد شد. صفحه و کارت دوز فعلی پس از آزمون نسخهٔ اصلی حذف و به این بازی منتقل‌شده وصل می‌شوند.
