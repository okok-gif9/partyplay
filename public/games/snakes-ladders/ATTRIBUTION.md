# Attribution — Snakes Ladders React source

This directory contains a localized, statically built derivative of:

- Project: `mohammadnedaei/Snakes-Ladders-React`
- Source: https://github.com/mohammadnedaei/Snakes-Ladders-React
- Copyright: Mohammad Nedaei, 2022
- License: MIT (full text in `LICENSE`)

PartyPlay adaptations are limited to Persian localization, right-to-left
presentation, GitHub Pages-relative asset paths, iframe embedding, and a fix
that makes the source project's existing CPU setting perform automated dice
rolls. The original board, rules, player configuration, animations, dice
component, source asset artwork, and game flow remain from the original project.
